# Provenance

- Sources consultees par `scripts/access_cascade.py` : Europe PMC, HAL, Unpaywall, OpenAlex et Semantic Scholar.
- Code dans ce plugin : client local original, stdlib seule, avec cache `~/.cache/litaccess/`.
- Donnees sous licence : aucun PDF d'editeur n'est telecharge automatiquement par ce skill.

Politique de droits : le skill maximise les voies legales d'acces ouvert et prepare le hand-off humain vers la bibliotheque ou le TDM institutionnel. Il ne contourne aucun paywall et ne redistribue aucun plein texte sous licence.

Garde-fou : un TLDR Semantic Scholar est un substitut de pertinence, jamais une source citable pour un claim.
