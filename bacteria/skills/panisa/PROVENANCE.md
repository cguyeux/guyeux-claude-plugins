# Provenance et droits

- Origine : skill local redige pour orchestrer panISa dans les campagnes de recherche du groupe Guyeux.
- Logiciel appele : panISa, Treepong et al., Bioinformatics 2018, DOI `10.1093/bioinformatics/bty479`.
- Redistribution : ce repertoire ne vendore pas le code de panISa ni ses donnees ; il fournit une procedure et un script d'orchestration local.
- Dependances privees : les chemins de calcul et les alias SSH decrivent l'infrastructure locale et doivent etre verifies avant chaque campagne.

## Garde-fou

Ne jamais lancer une campagne complete avant le pilote falsifiant documente dans `SKILL.md`. Aucun identifiant, mot de passe ni cle privee ne doit etre ajoute au skill.
