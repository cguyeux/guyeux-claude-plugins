# Provenance

- Source externe consultee : bio.tools registry API, service public ELIXIR.
- URL API : `https://bio.tools/api/tool/`.
- Licence des metadonnees : indiquee par bio.tools comme CC BY 4.0 sur la page About.
- Code importe dans ce skill : aucun code bio.tools n'est embarque ; `scripts/biotools_scan.py` est un client local original.
- Usage Codex : interroger l'API, comparer aux `SKILL.md` locaux et aux connaissances `~/.Codex/knowledge/` puis `~/.claude/knowledge/`.

Garde-fou : les resultats bio.tools sont des pointeurs documentaires. Une fiche trouvee ne valide pas la pertinence scientifique de l'outil pour un projet MTBC ou pathogenomique sans relecture humaine.
