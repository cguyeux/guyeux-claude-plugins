# Coll 2014 — A robust SNP barcode for typing MTBC strains

## Citation

Coll F, McNerney R, Guerra-Assunção JA, Glynn JR, Perdigão J, Viveiros M,
Portugal I, Pain A, Martin N, Clark TG. **A robust SNP barcode for typing
Mycobacterium tuberculosis complex strains.** *Nature Communications* 5:4812
(2014). DOI: [10.1038/ncomms5812](https://doi.org/10.1038/ncomms5812)

PDF: `~/Documents/codes/MTBC/TBannotator/data/TB_Coll_2014B.pdf`

## Key facts

- **62 SNPs** proposed to discriminate the 7 major MTBC lineages and 55
  sub-lineages.
- Built from whole-genome sequences of **1,601 isolates** from 11 independent
  studies, with global geographic representation.
- Identified ~92,000 SNPs across the collection; ~7,000 strain-specific.
- **Consistent with the RD (regions of difference) classification system.**
- First SNP-based barcode to cover all 7 main lineages (1, 2, 3, 4, 5, 6, 7).
- Lineages 1, 5, 6, 7 = **ancient** ; Lineages 2, 3, 4 = **modern**.
- Lineages 5–6 = *M. africanum* (West Africa).
- Lineage 7 = intermediate, Ethiopia/Horn of Africa.

## How the system is named in TBannotator/lignees.py

System key: `"Coll"` in `lignees.py`. Each entry is a tuple
`(lineage_code, defining_SPDI)` such as
`("4", "NC_000962.3:648856:C:T")`.

## Notes

- The Coll 2014 system is the **most widely used barcode for MTBC** and is
  the default reference in many epidemiology pipelines.
- For MTBC lineage 5/6 sub-classifications, refer instead to **Coscolla 2021**
  (Phylogenomics of M. africanum).
- The Coll system does **NOT** cover the new lineages 8, 9, 10, nor
  recent sub-lineages discovered after 2014. Use **Napier 2020** or
  **Freschi 2021** for newer additions.

## Strengths

- Robust on whole-genome data.
- Stable markers (SNPs are mutational invariants).
- Hierarchical (lineages → sub-lineages → families).
- Compatible with the historical RD-based classification.

## Limitations

- Built before the discovery of lineages 7–10.
- Limited animal lineage coverage (M. bovis, M. caprae, M. orygis are not
  in the original 62-SNP set).
- For modern usage, **always cross-reference with the authoritative home
  registry `barcode_complete.tsv` (+ `bdd/actuelle`)**; for a "moi vs Coll"
  mapping use `barcoding_v2/taxonomy_crossmap.tsv` (filter `system='Coll'`).
  See `SOURCES_OF_TRUTH.md`. (Not `snp_barcoding.csv` — obsolete v1.)
