# Plugin `web`

> Un plugin pour le développement web

## Rôle dans un projet M. tuberculosis

Développement et test d'applications web, transverse. Par exemple pour exposer une base ou un tableau de bord de résultats MTBC.

Skills propres (canoniques) : **2** ; skills partagés utilisés (symlinks) : **0**.

[Retour à l'index de la documentation](README.md)

## Skills propres

Sommaire : [frontend-design](#frontend-design) ; [webapp-testing](#webapp-testing)

### frontend-design

Create distinctive, production-grade frontend interfaces with high design quality

Compétences : when the user asks to build web components, pages, or applications ; Generates creative, polished code that avoids generic AI aesthetics

### webapp-testing

Toolkit for interacting with and testing local web applications using Playwright. Supports verifying frontend functionality, debugging UI behavior, capturing browser screenshots, and viewing browser logs.
