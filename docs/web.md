# Plugin `web`

> Un plugin pour le développement web

## Rôle dans un projet M. tuberculosis

Développement et test d'applications web, transverse. Par exemple pour exposer une base ou un tableau de bord de résultats MTBC.

Skills propres (canoniques) : **2** ; skills partagés utilisés (symlinks) : **0**.

[Retour à l'index de la documentation](README.md)

## Skills propres

Sommaire : [frontend-design](#frontend-design) ; [webapp-testing](#webapp-testing)

### frontend-design

Crée des interfaces frontend distinctives et de qualité production, avec une exigence esthétique élevée.

Compétences : l'utilisateur demande de construire des composants, pages ou applications web ; générer un code soigné et créatif qui évite l'esthétique générique des IA

### webapp-testing

Pilote et teste une application web locale avec Playwright : navigation, remplissage de formulaires, parcours de clics, assertions sur le DOM rendu, captures d'ecran et lecture des journaux de la console du navigateur.

Compétences : verifier qu'un frontend local fonctionne ; reproduire un bug d'interface ; controler une page apres une modification ; capturer une copie d'ecran d'un serveur de developpement ; inspecter les erreurs console et reseau depuis un navigateur sans affichage
